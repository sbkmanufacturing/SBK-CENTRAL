# **App Name**: SBK Vision

## Core Features:

- Home: Display key navigation and company info.
- Dashboard: Central hub with links to main app functions.
- Work Orders: Page for creating and viewing work orders.
- Job Cards: Manage and track job card details.
- CTP Control: Control plate production and track orders.
- Inventory Hub: Track stock and usage details.
- HR Records: Organized records accessible to the Admin tool.
- Online Storage: Store app data online using Firebase
- Cross-Device Access: Make app data accessible from any device.
- Publish App: Publish the application online.

## Style Guidelines:

- A deep blue (#30475E) to evoke trust, stability, and sophistication, reflecting SBK Manufacturing's reliability.
- A very light gray (#F0F4F8), providing a clean, neutral backdrop that enhances readability and reduces eye strain.
- A muted gold (#B09F82) as a sophisticated highlight for key interactive elements and calls to action.
- 'Inter' (sans-serif) for headings and body text; provides a modern and clean look suitable for dashboards.
- Use a consistent set of professional icons to represent each module on the dashboard.
- Employ a clean, grid-based layout to ensure the information is well-organized and accessible.
- Incorporate subtle animations and transitions, such as a gentle fade-in when loading content.
